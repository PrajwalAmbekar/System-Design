# Code 4 — Electricity Billing CLI

Day 2 · Functions & Control Flow · Phase 0 (C++ prerequisites)

A command-line tool that turns meter units into a bill using tiered slab pricing,
a fixed charge and tax. Money is stored as integer paise (`long long`), never `double`.

## Usage

```bash
./bill UNITS [SOLAR_UNITS]
```

- `UNITS`: units consumed, integer 0..100000
- `SOLAR_UNITS` (optional): units generated by solar, integer 0..100000, default 0

## Rules

| Rule | Value |
|---|---|
| Slab 1 (units 1–100) | 400 paise/unit |
| Slab 2 (units 101–300) | 700 paise/unit |
| Slab 3 (units 301+) | 1000 paise/unit |
| Net units | `max(0, UNITS - SOLAR_UNITS)` |
| Fixed charge | 5000 paise, always charged (even at 0 units) |
| Tax | 5% of (energy + fixed), integer division |

Each unit is charged at **its own slab's rate** (tiered), not at the rate of the slab the total lands in.

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Success |
| 2 | Wrong number of arguments |
| 3 | Non-numeric or out-of-range argument |

Errors and logs go to stderr; only the bill goes to stdout.

## Build and run

```bash
mkdir -p ../../build
g++ -std=c++20 -Wall -Wextra -g solution/code4_solution.cpp -o ../../build/bill
../../build/bill 350 50
```

## Verified examples

| Command | Net | Energy | Fixed | Tax | Total |
|---|---|---|---|---|---|
| `./bill 350 50` | 300 | Rs 1800.00 | Rs 50.00 | Rs 92.50 | Rs 1942.50 |
| `./bill 250` | 250 | Rs 1450.00 | Rs 50.00 | Rs 75.00 | Rs 1575.00 |
| `./bill 400` | 400 | Rs 2800.00 | Rs 50.00 | Rs 142.50 | Rs 2992.50 |
| `./bill 50 80` | 0 | Rs 0.00 | Rs 50.00 | Rs 2.50 | Rs 52.50 |
| `./bill 0` | 0 | Rs 0.00 | Rs 50.00 | Rs 2.50 | Rs 52.50 |

Error cases: `./bill` and `./bill 1 2 3` exit 2; `abc`, `12abc`, `100001`, `5 -1` exit 3.

## Design

```text
main  ──►  Tariff  ──creates──►  Bill
 │
 └──►  Logger (stderr)
```

- **Tariff**: owns every pricing rule (slab limits, rates, fixed charge, tax). No I/O.
- **Bill**: immutable result (net units, energy, fixed, tax, total). No pricing logic.
- **Logger**: writes messages to stderr.
- **main**: parses and validates arguments, calls `Tariff`, prints the `Bill`, maps failures to exit codes.
- `parseInt` and `printMoney` are free functions outside the domain classes.

## Concepts used

- Overloading: `billFor(units)` calls `billFor(units, solar)`, so the rules live in one place
- Default arguments on the `Tariff` constructor
- `const` methods and an `explicit` constructor
- Reference output parameter (`parseInt(text, int& out)`)
- `if` chains and early returns; multiply before divide for integer money math

## Edge cases handled

- Solar greater than units → net clamped to 0, fixed charge still applies
- Zero units → fixed charge and tax still apply
- Partial numbers (`12abc`) and numbers too large for `int` are rejected
- Values outside 0..100000 are rejected before any billing

## Limitations

- Tariff values are hard-coded defaults, not read from a config file or database
- Surplus solar is not credited to the customer
- Tax and slab rounding drop fractions of a paisa
- One bill per run, no persistence, no customer or meter model
- Errors use return codes; a consistent error type comes in a later topic
